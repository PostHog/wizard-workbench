# PostHog MCP Analytics — Instrumentation Report

## Summary

Instrumented the `workbench-stdio-server` MCP server (TypeScript, official `@modelcontextprotocol/sdk`, STDIO transport) with PostHog MCP analytics using **Path A** (`instrument(server, posthog)`). Every tool call, agent intent, and failure is now captured as a `$mcp_*` event in PostHog.

## Changes Made

### Files Modified

| File | Change |
|------|--------|
| `src/index.ts` | Added `PostHog` client (module-scope), `instrument(server, posthog)` call immediately after `McpServer` construction, and a `SIGTERM` shutdown handler that calls `posthog.shutdown()` to flush in-flight events. |
| `package.json` | `@posthog/mcp@0.9.1` and `posthog-node` added to `dependencies` by `npm install`. |

### Files Created

| File | Purpose |
|------|---------|
| `.env` | `POSTHOG_PROJECT_TOKEN` and `POSTHOG_HOST` environment variables. |
| `package-lock.json` | Lockfile generated by `npm install`. |

### Key code added to `src/index.ts`

```ts
import { PostHog } from 'posthog-node'
import { instrument } from '@posthog/mcp'

const posthog = new PostHog(process.env.POSTHOG_PROJECT_TOKEN!, {
    host: process.env.POSTHOG_HOST,
})

const server = new McpServer({ name: 'workbench-stdio-server', version: '1.0.0' })
instrument(server, posthog)  // Path A — wraps the McpServer

// ...tools registered as before...

process.on('SIGTERM', async () => {
    await posthog.shutdown()
    process.exit(0)
})
```
