# PostHog post-wizard report

The wizard has completed a deep integration of PostHog analytics into the Jetchat Android (Kotlin/Jetpack Compose) app. A new `JetchatApplication` class was created to initialize the PostHog Android SDK on app startup, with session replay, lifecycle event tracking, screen view tracking, and automatic error capture enabled. The `local.properties` file stores the PostHog API key and host, which are surfaced to Kotlin via `BuildConfig` fields generated by `app/build.gradle.kts`. Twelve events spanning the key user flows — authentication, messaging, voice recording, emoji and attachment usage, profile navigation, channel switching, and widget installation — are now captured across six files. User identification is performed at login via `PostHog.identify()`, and the session is reset at logout via `PostHog.reset()`.

| Event Name | Description | File |
|---|---|---|
| `user_logged_in` | User successfully logs in with a username and password. | `MainViewModel.kt` |
| `user_logged_out` | User logs out of the application. | `MainViewModel.kt` |
| `message_sent` | User sends a text message in a conversation channel. | `Conversation.kt` |
| `drag_drop_message_received` | User drops content into the conversation via drag and drop to send as a message. | `Conversation.kt` |
| `voice_recording_started` | User begins recording a voice message. | `RecordButton.kt` |
| `voice_recording_completed` | User completes and sends a voice message recording. | `RecordButton.kt` |
| `voice_recording_cancelled` | User cancels a voice message recording by swiping away. | `RecordButton.kt` |
| `emoji_selected` | User selects an emoji from the emoji picker to add to their message. | `UserInput.kt` |
| `attachment_selector_opened` | User opens an attachment input selector such as photo, map, or video call. | `UserInput.kt` |
| `profile_viewed` | User navigates to view another user's profile screen. | `ProfileFragment.kt` |
| `channel_switched` | User switches to a different chat channel from the navigation drawer. | `JetchatDrawer.kt` |
| `widget_added_to_home_screen` | User initiates adding the Jetchat widget to their device home screen. | `JetchatDrawer.kt` |
