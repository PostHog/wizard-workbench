# PostHog post-wizard report

The wizard has completed a deep integration of PostHog analytics into the Acme AI FastAPI SaaS application. A new `app/analytics.py` module was created to initialize the `Posthog` client using the instance-based API with exception autocapture enabled. The client is initialized once at import time using settings from environment variables, and a flush call is wired into the app's lifespan shutdown. Event capture was added to six route files covering all critical business flows: authentication, AI content generation, API key management, and account settings.

| Event Name | Description | File |
|---|---|---|
| `user_signed_up` | User completes registration via the signup form. Sets `$set` person property for initial credits. | `app/routers/auth.py` |
| `user_logged_in` | Existing user authenticates successfully. Tracks `login_method`. | `app/routers/auth.py` |
| `user_logged_out` | Authenticated user logs out. | `app/routers/auth.py` |
| `content_generated` | AI content generation succeeds. Tracks `generation_type`, `credits_used`, `credits_remaining`. | `app/routers/generate.py` |
| `content_generation_failed` | Generation blocked due to insufficient credits. Tracks `generation_type`, `credits_needed`, `credits_available`. | `app/routers/generate.py` |
| `api_key_created` | User creates a new API key. Tracks `key_name`. | `app/routers/api_keys.py` |
| `api_key_creation_blocked` | API key creation blocked because the user hit the 5-key limit. Tracks `active_key_count` and `limit`. | `app/routers/api_keys.py` |
| `api_key_revoked` | User deactivates an existing API key. Tracks `key_name`. | `app/routers/api_keys.py` |
| `settings_updated` | User updates their account email. Tracks `fields_changed`. | `app/routers/settings.py` |
| `password_changed` | User successfully changes their password. | `app/routers/settings.py` |
