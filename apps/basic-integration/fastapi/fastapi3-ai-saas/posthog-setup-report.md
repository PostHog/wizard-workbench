# PostHog post-wizard report

The wizard has completed a deep integration of PostHog analytics into the Acme AI FastAPI SaaS application. The integration covers the full user journey: account creation and authentication, AI content generation (the core business action), credit failure tracking, API key management, and account settings changes. A per-request ASGI middleware wraps every HTTP request in a PostHog context and automatically identifies authenticated users, so all route handlers can call `capture()` without setup boilerplate.

| Event | Description | File |
|---|---|---|
| `user_signed_up` | A new user successfully creates an account via the signup form. | `app/routers/auth.py` |
| `user_logged_in` | An existing user successfully authenticates via the login form. | `app/routers/auth.py` |
| `user_logged_out` | An authenticated user ends their session by logging out. | `app/routers/auth.py` |
| `content_generated` | A user successfully generates AI content (blog, email, or social post). | `app/routers/generate.py` |
| `content_generation_failed` | A content generation request fails because the user has insufficient credits. | `app/routers/generate.py` |
| `api_key_created` | A user creates a new API key for programmatic access. | `app/routers/api_keys.py` |
| `api_key_revoked` | A user deactivates and removes one of their API keys. | `app/routers/api_keys.py` |
| `settings_updated` | A user successfully updates their account settings (e.g., email address). | `app/routers/settings.py` |
| `password_changed` | A user successfully changes their account password. | `app/routers/settings.py` |
