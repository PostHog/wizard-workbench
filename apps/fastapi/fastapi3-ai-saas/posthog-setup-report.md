# PostHog post-wizard report

The wizard has completed a deep integration of PostHog into the Acme AI FastAPI SaaS application. Here is a summary of all changes made:

**`requirements.txt`** — Added `posthog>=3.0.0` as a project dependency.

**`.env`** — Added `POSTHOG_API_KEY`, `POSTHOG_HOST`, and `POSTHOG_DISABLED` environment variables.

**`app/config.py`** — Extended the `Settings` Pydantic model with three new fields: `posthog_api_key`, `posthog_host` (defaulting to `https://us.i.posthog.com`), and `posthog_disabled`.

**`app/middleware.py`** — Created `PostHogMiddleware`, a pure ASGI middleware that wraps every HTTP request in a PostHog context using `new_context()`. For authenticated users it calls `identify_context(user.email)` and tags `is_active`, ensuring all events captured during a request are automatically associated with the correct user.

**`app/main.py`** — Added PostHog initialisation in the FastAPI `lifespan` context manager: sets `posthog.api_key`, `posthog.host`, and `posthog.debug` on startup, calls `posthog.flush()` on shutdown to ensure all queued events are delivered. Registered `PostHogMiddleware` on the app.

**`app/routers/auth.py`** — Added `user_signed_up`, `user_logged_in`, and `user_logged_out` events with relevant properties and user identification.

**`app/routers/generate.py`** — Added `content_generated` (with generation type, credits used/remaining, and prompt length) and `generation_failed_insufficient_credits` (with type and credit counts) events.

**`app/routers/api_keys.py`** — Added `api_key_created` (with active key count) and `api_key_revoked` events.

**`app/routers/settings.py`** — Added `settings_updated` (with list of changed fields) and `password_changed` events.

**`app/routers/pages.py`** — Added `dashboard_viewed` event (with credits remaining) fired on every dashboard page load.
