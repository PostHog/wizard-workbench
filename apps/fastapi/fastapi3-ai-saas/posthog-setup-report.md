# PostHog post-wizard report

The wizard has completed a deep integration of PostHog analytics into your Acme AI FastAPI application. Here's a summary of all changes made:

**`requirements.txt`** — Added `posthog>=3.0.0` dependency.

**`app/config.py`** — Added `posthog_project_token` and `posthog_host` fields to the `Settings` class, loaded from environment variables `POSTHOG_PROJECT_TOKEN` and `POSTHOG_HOST`.

**`.env`** — Created with `POSTHOG_PROJECT_TOKEN` and `POSTHOG_HOST` values. Already covered by `.gitignore`.

**`app/main.py`** — Added PostHog initialization in the lifespan startup (sets `api_key`, `host`, `debug`) and `posthog.flush()` on shutdown to ensure all events are sent. Also registered `PostHogMiddleware`.

**`app/middleware.py`** — Added `PostHogMiddleware`, a pure ASGI middleware that wraps every HTTP request in a `new_context()`. For authenticated users, it calls `identify_context(str(user.id))` and tags their `credits` balance as a person property, ensuring all downstream captures are automatically associated with the correct user.

**`app/routers/auth.py`** — Added `user_signed_up` and `user_logged_in` events with user identification on success; `login_failed` on bad credentials.

**`app/routers/generate.py`** — Added `content_generated` event on successful AI content generation (with type, credits used/remaining, prompt length); `generation_failed` on insufficient credits.

**`app/routers/api_keys.py`** — Added `api_key_created` and `api_key_revoked` events.

**`app/routers/settings.py`** — Added `settings_updated` on successful email change, and `password_changed` on successful password change.

## Next steps

Create an **"Analytics basics"** dashboard in PostHog at https://us.posthog.com/project/2/dashboard with these five suggested insights:

1. **Signup → First Generation Funnel** — Funnel from `user_signed_up` → `content_generated`. Tracks how many new users convert to using the core AI feature.

2. **Content Generated by Type** — Bar chart of `content_generated` broken down by `generation_type` property (blog / email / social). Shows which content types are most popular.

3. **Daily Active Users** — Unique users per day combining `user_logged_in` and `content_generated`. Core engagement metric.

4. **Credit Exhaustion Rate** — Trend of `generation_failed` events over time. Rising numbers indicate users hitting credit limits — a signal for upsell opportunities.

5. **API Key Adoption** — Trend of `api_key_created` vs `api_key_revoked`. Shows developer/programmatic usage adoption.
